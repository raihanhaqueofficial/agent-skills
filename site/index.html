Install

Copy one folder.

Skills are plain Markdown. Any agent that reads a skills directory can use them — no build step, no account, no service.

$ git clone https://github.com/raihanhaqueofficial/agent-skills

# copy one skill into your agent's skills root
$ cp -r agent-skills/skills/token-lean-answers ~/.your-agent/skills/

# verify compliance before you fork or contribute
$ ./scripts/compliance-check.sh

Principles

What these have in common.

Verify with a real check
An exit code proves nothing — probe the artifact and say what came back.
Measure before claiming
Figures carry a date and a source. Anything thin is labelled reported, not measured.
Report what is unknown
A skill that hides its gaps is worse than no skill at all.
No telemetry
Nothing dials out. Where an upstream source did, those parts were removed and the removal recorded.
No personal data
Enforced by an automated gate that runs on every push and pull request.

Compliance

Documented, not assumed.

A licence is not a trademark, and a privacy policy is not boilerplate. Each of these says a true thing about what the project does.

LICENSE · MIT TRADEMARK.md PRIVACY.md · collects nothing DISCLAIMER.md SECURITY.md CONTRIBUTING.md CODE_OF_CONDUCT.md CHANGELOG.md CI compliance gate

No separate Terms & Conditions, deliberately. MIT is the terms — adding restrictive terms on top would contradict the licence. What a licence cannot grant is rights to a name, so that document exists instead.

FAQ

Short answers.

What is this?

A small, opinionated set of skills for AI coding agents, built while doing real video, research and tooling work. They are written to be portable and verifiable, not clever.

Is it free?

Yes — MIT. Use it, modify it, ship it commercially.

Does anything phone home?

No. There are no network calls to my servers, no analytics, no accounts, no cookies. Where an upstream tool did report usage, those components were removed and the change recorded.

Why no Terms & Conditions file?

Because MIT already is the terms. Adding a restrictive T&C over a permissive licence creates a contradiction. The trademark policy covers the part a licence genuinely cannot.

Can I contribute?

Yes. Two rules: no personal data, no telemetry. Run ./scripts/compliance-check.sh before you push — it is the same gate CI runs.
