# Privacy

## What this project does with your data

**Nothing.** There is no data collection, because there is no mechanism for it.

Concretely, this repository and the software in it:

- make **no network requests** to the author's servers, or to any analytics,
  crash-reporting, telemetry or advertising service;
- have **no accounts, no sign-in, no cookies, no tracking pixels, no
  fingerprinting**;
- **send nothing back** — no usage counts, no feature flags, no "anonymous
  statistics";
- run **entirely on your own machine**. Video rendering, file processing and
  analysis all happen locally.

This is not a policy promise about restraint. It is an architectural
statement: the code was specifically built to avoid telemetry. Where an
upstream source did phone home, the vendor components were removed and the
change is recorded in [`NOTICE`](NOTICE).

## Third-party software you install

The skills reference third-party tools you install yourself (`ffmpeg`,
`yt-dlp`, Whisper, Chromium, and so on). **Those are governed by their own
privacy practices, not by this document.** Check them independently.

## This repository on GitHub

Hosting this repository on GitHub is subject to GitHub's own privacy
statement, which is outside the author's control.

## Your own content

Nothing you run through this software is uploaded, transmitted, or retained
by the author. What you process stays with you.

## Changes

This is a statement of what the software does, not a promise about future
versions. If that ever changed, the change would be recorded in
[`CHANGELOG.md`](CHANGELOG.md) and in [`NOTICE`](NOTICE), prominently.
